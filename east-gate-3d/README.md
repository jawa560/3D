# 迎曦門一萬步 — 新竹東門城程序化 3D

依照片推估、以程式碼重建新竹東門城（迎曦門）的 3D 模型，並把整座城門拆成 **恰好 10,000 個建造步驟**：每一步放上一個真實構件（一塊砂岩、一塊紅磚、一根柱、一片瓦……），可逐步播放、拖曳進度、或跳到任一階段。

## 檔案

| 檔案 | 說明 |
|---|---|
| `index.html` | Three.js（r128，自 cdnjs 載入）互動頁面：播放／暫停、速度、進度條、階段跳轉、步驟清單、複製 CSV |
| `gate-steps.js` | 一萬步產生器，Node.js 與瀏覽器共用；`GateModel.build()` 回傳 10,000 個構件（位置、尺寸、旋轉、顏色、階段、說明） |
| `steps.csv` | 匯出的完整步驟清單（UTF-8 BOM，Excel 可直接開啟） |

## 使用

- 直接以瀏覽器開啟 `index.html`（需可連線 cdnjs 以載入 Three.js），或在此資料夾執行任一靜態伺服器，例如 `python3 -m http.server`，再開啟 `http://localhost:8000/`。
- 操作：單指或左鍵拖曳旋轉；雙指拖曳、右鍵或 Shift 加拖曳平移；捏合或滾輪縮放。面板可按「收合」縮成只剩步數、播放鍵與進度條，畫面會自動置中在面板以外的區域；手機預設為收合。
- 重新產生 CSV：`node -e "const G=require('./gate-steps.js');const m=G.build();/* 見 index.html 的 copy 邏輯 */"`

## 模型說明

- 座標：y 向上、x 為城門長軸、z 為穿越拱門方向，單位公尺。台座 22 × 11 × 7 m，含半圓拱道（半徑 2.8 m）與 22 道石環穹窿。
- 樓閣為二重簷：下層為環繞上層樓身的腰簷，上層為歇山頂，四角以 `lift · |u|³ · v²` 產生翹角，正脊兩端以五次曲線抬升成燕尾。
- 屋面曲線採凹面（上陡下緩）：`y = top − drop · (0.45v + 0.55(1 − (1 − v)²))`。
- 所有構件以 Three.js `InstancedMesh`（箱體、圓柱、球體三組）繪製，依步驟編號排序，播放時只需調整各組的 `count`；新放上的構件有落下動畫。
- 比例與配色依照片校正：拱寬約為台座寬 0.27 倍、女牆為白色粉刷、脊與封簷板為藍色、上層為白牆小方窗，簷柱外側各懸一盞白燈籠。頁面的「照片視角」按鈕會把相機移到與照片相同的低角度正面。
- 廣場鋪面階段會自動補足構件數至 10,000，因此調整其他參數後總數仍恰為一萬。
